ESP32 Meteostation

Welcome to my first IOT project!


Created as an IoT .NET programming course project
with main purpose of getting familiar with programming,
assembling and testing embedded systems.


Sensors:
1. BME280 - temperature, humidity
2. DHT22 - temperature, humidity
3. NEO-6M - GPS
Base: ESP32 S3


Backend: ASP.NET Core Minimal API
DB: Azure SQL
